# 对照品管理 Fable 原型

本目录保存由 Fable 生成的对照品管理交互原型。

该原型仅用于参考：

- 业务模块与字段集合
- 字段排列与表单分组
- 列表、详情及操作流程
- 页面信息层级

正式页面必须沿用现有 LIMS 的 React、TypeScript、Ant Design Pro、权限、路由、状态组件和 API 架构。

实施优先级：

1. 已冻结的业务设计与后端 API 契约
2. 现有 LIMS 的视觉和组件规范
3. 现有同类页面的实现方式
4. Fable 原型中的字段和流程参考

禁止通过 iframe 嵌入该原型，也不得将原型生成的整段 HTML、CSS 或 JavaScript 直接作为生产代码。
