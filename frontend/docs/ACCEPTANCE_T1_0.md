# T1.0 验收说明（ACCEPTANCE_T1_0）

LIMS 前端 MVP（mock 版）冻结验收。**全部数据走前端 mock adapter，不接真实后端。**

## 1. 启动步骤

```bash
cd frontend
npm install        # 首次
npm run dev        # http://localhost:5173
# 质量门禁
npm run typecheck
npm run lint
npm run build
```

## 2. 测试账号（任意密码）

|---|---|---|
| admin | admin | 系统管理员 |
| director | director | 王主任 |

> 退出后回到 /login；不同角色左侧菜单不同（仅 admin 有「系统管理」）。

## 3. 各角色验收路径

- **admin/director**：可见全部项目/实验/日报/库存；可新建项目、确认日报、库存入库/调整/冻结、确认出库。
- **project_manager(pm 张项目)**：仅见所属项目(PRJ-A/B/D)；仅 PRJ-A/PRJ-D 可编辑（本人负责）；可确认本负责项目下成员日报与实验出库；库存只读。
- **operator(op 李操作)**：仅见本人参与项目与本人相关实验/日报；可填写实验物料使用但不可确认出库；库存只读；无新建/编辑项目。

## 4. 验收项

### 项目
- [ ] 列表搜索(代码/名称/类型/负责人/状态)、重置、分页。
- [ ] 负责人下拉仅 admin/director/pm；operator 仅作组员。
- [ ] pm 新建项目负责人锁定本人；仅可编辑本人负责项目。
- [ ] 详情「成员」Tab：负责人与组员分区；可增删 operator 组员（按权限）。

### 实验记录
- [ ] 列表搜索(编号/标题/项目/状态/负责人/计划日期)、分页。
- [ ] 负责人/参与人仅限所属项目人员；切项目联动。
- [ ] 物料使用表：选批次显示库存，实际>库存行标红。
- [ ] 详情「物料使用」确认出库扣库存，已出库不重复扣减；catalyst 不足行记缺口。

### 工作日报
- [ ] 列表搜索(日期/提交人/项目/实验/状态/关键词)、分页。
- [ ] 提交人锁定当前用户；项目变化→关联实验联动。
- [ ] 草稿→提交→(确认/退回必填原因)→流程正常；operator 仅见本人。

### 库存
- [ ] 列表搜索(编号/名称/CAS/类别/批号/供应商/库位/状态)、分页；低/过期行高亮。
- [ ] 批次详情：基础信息 / 库存流水 / 关联实验(显示项目名) / 备注附件占位。
- [ ] 入库/调整/冻结仅 admin/director 可见；流水正确生成。

### Dashboard
- [ ] 卡片：进行中/项目总数、进行中/实验总数、待确认日报、低库存/已用尽批次。
- [ ] 列表：近期实验、近期日报、库存预警；点击跳转。

### 通用
- [ ] 列表无数据 Empty；加载 loading；详情 id 不存在显示错误+返回；service 异常不白屏。

## 5. 已知占位功能（T1.0 内）

- 附件/图谱：mock 列表，无真实上传/下载/预览（MinIO 后续）。
- 操作记录/操作日志：mock 时间线，非后端审计。
- 改密：首登仅 banner 提示，无完整改密流程。
- 库存低库存阈值：由 mock status 驱动，无 `low_stock_threshold` 动态计算。
- 样品/检测与审核(/samples、/testing)、系统管理(/admin)：高质量占位页。
- 代填他人日报：未实现。

## 6. 不在 T1.0 范围（T1.1+）

- 接真实后端 API（切换 `USE_MOCK=false` + `http.request`）。
- 真实文件上传 / 缩略图 / 下载 / 预览。
- 样品-检测-结果 全流程、审核工作台。
- 库存阈值预警系统、条码/扫码。
- 日报作废、已确认日报修订记录。
- 完整改密 / refresh 真撤销。
